Generate a `DIGEST.md` for project onboarding. Accepts an optional output path
argument (default: `DIGEST.md` at project root).

## Pipeline

### Phase 1 — Research (parallel)

Spawn 3 `researcher` agents (via `subagent_type: "lineup:researcher"`):

- **A — Structure**: directory tree, dependencies, build system, config files
- **B — Entry Points**: main entry points, core modules, public API, data models
- **C — Tests & DX**: test setup, existing docs, dev workflow, CI/CD

Cap each output at ~1500 words.

### Phase 2 — Structure

Spawn 1 `architect` agent with all researcher outputs. Produce an outline:
Project Overview → Architecture → Modules → Data Flow → Patterns →
Getting Started → Contributing.

### Phase 3 — Write

Spawn 1 `documenter` agent with the architect's outline. Write the markdown
to the target path. Must begin with:

```
<!-- Auto-generated by Lineup digest. Regenerate with: {{CMD_DIGEST}} -->
```

Keep under 500 lines. Include file path references throughout.

## Completion

Report: "Digest written to `<path>`. Regenerate with `{{CMD_DIGEST}}`."
