Claude Code · Codex CLI · OpenCode

## Core design

<CardGrid>
  <Card title="Triage-first">
    Stage 0 classifies task complexity and selects models per role. Simple tasks run on Haiku, complex ones on Opus. No manual configuration.
  </Card>
  <Card title="Resumable">
    Each stage caches its output. Interrupted runs restart from the last completed stage, not from scratch.
  </Card>
  <Card title="Token-efficient">
    Staged prompt loading, lazy agent instantiation, and ephemeral file references keep context windows lean.
  </Card>
</CardGrid>

---

**Native engine, shipped.** Lineup now runs deterministic orchestration in the CLI: typed stages, artifact validation, task compilation, retry state, gates, and resumable runs all execute natively. Skills stay thin and host-specific while the runtime stays shared.
