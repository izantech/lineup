## Works with

Claude Code · Codex CLI · OpenCode

## Core design

<CardGrid>
  <Card title="Start anywhere">
    Run Lineup directly in your terminal or from an installed host command. The engine stays the same either way.
  </Card>
  <Card title="Resume instead of restart">
    Every run keeps its state and artifacts, so blocked or failed work can be inspected and resumed without redoing completed stages.
  </Card>
  <Card title="Thin host integrations">
    Claude Code, Codex CLI, and OpenCode stay lightweight. Lineup keeps the orchestration inside the CLI so behavior stays consistent.
  </Card>
</CardGrid>

---

**Built for everyday terminal use.** Lineup helps with feature work, bug fixes, security reviews, refactors, explanations, and docs. The site focuses on install and usage. Deep runtime details live in the repository docs for contributors and advanced integrations.

---

## Install

```bash
npm install -g @izantech/lineup-cli
lineup install
```

## First run

```bash
lineup start "Review the auth middleware in src/auth.ts and identify security gaps"
```

`lineup start` is the easiest first-run path. It scaffolds Lineup if needed, checks git readiness, and only starts the pipeline once the repo is ready.
